# 🌤️ Weather App - Angular

Aplicação de previsão do tempo desenvolvida para praticar conceitos avançados de Angular 21 e integração com APIs REST.

## 🚀 Tecnologias
- **Angular 21** (Standalone Components & Signals)
- **TypeScript**
- **RxJS** para chamadas assíncronas
- **OpenWeatherMap API** para dados climáticos

## 🛠️ Como executar o projeto
1. Clone o repositório: `git clone https://github.com/Glaucombribeiro/weather-app-angular.git`
2. Entre na pasta: `cd weather-app-angular`
3. Instale as dependências: `npm install`
4. Inicie o servidor: `ng serve`
5. Acesse `http://localhost:4200` no navegador.
